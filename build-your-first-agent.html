1

Make a folder

On your computer, make one new folder. Name it after your business. That's the whole step.

mkdir my-business cd my-business
2

Give it a memory

Open a terminal in that folder and run claude. Paste this in:

Create a file in this folder called CLAUDE.md. Before you write it, ask me 3 questions: what my business does, who my ideal client is, and how I like to talk to people. Then write my answers into the file.
3

Prove it remembers

Close that chat completely. Open a brand new one in the same folder with claude again, and ask:

What do you already know about my business?

If it answers correctly without you re-explaining anything — that's the whole trick. It read the file.

4

See what you just built

That folder and that one file are the entire foundation of what people call "agentic AI." Not a smarter chatbot — a system that keeps its own notes and acts on them, so you stop repeating yourself. Everything bigger (routing client messages, running whole workflows, using more than one AI tool on the same files) is just more files added to that same folder.
