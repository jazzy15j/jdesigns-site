New to Claude Code? Start Here

Claude Code is the free tool from Anthropic that runs these commands. Already have it installed and your Business System built? Skip to "Install Your Commands" below.

1
Get a free Claude account — sign up here (includes a free week of Claude Pro).
2
Open Terminal (Mac) or PowerShell (Windows) and paste the command for your system below, then press Enter. It can sit with no text on screen for 10–30 seconds before anything prints — that's normal, it's downloading in the background. Don't retype or close the window, just wait.
3
Check it worked: type claude --version and press Enter — you should see a version number print.
Mac / Linux
Terminal
curl -fsSL https://claude.ai/install.sh | bash
Windows (PowerShell)
PowerShell
irm https://claude.ai/install.ps1 | iex

Claude Code itself is free to install. Using it requires a Claude Pro, Max, Team, Enterprise, or Console account — the sign-up link above gets you a free week of Pro to try it. You'll also need your Business System files (CLAUDE.md, my-business-system.md) already built — the commands read from those.

Still nothing after a minute, or an error appears? You're likely on a network that blocks the download — try npm install -g @anthropic-ai/claude-code instead (requires Node.js), or see code.claude.com/docs.

Open your terminal, navigate to your Business System folder, and run the install command for your operating system. All 6 commands will be installed automatically.

Terminal

Windows (PowerShell)
PowerShell
